# 🚀 SortX Visualizer

An interactive and visually engaging Sorting & Searching Algorithm Visualizer built with a strong focus on **creativity, real-time animation, and user understanding**.

🌐 **Live Demo**: https://tourmaline-kheer-32d00f.netlify.app/


## 🎯 Project Overview

SortX Visualizer helps users understand how different sorting and searching algorithms work through **dynamic animations, real-time operations, and intuitive UI interactions**.

Unlike traditional visualizers, this project focuses on:

* Clear step-by-step visualization
* Engaging UI/UX with animations
* Interactive learning experience

---

## ✨ Key Features

### 📊 Sorting Visualizations

* Bubble Sort
* Insertion Sort

## ⚙️ Implementation Flow

1. User selects algorithm
2. Array is generated/displayed
3. User chooses:

   * Auto Mode OR Manual Mode
4. Algorithm starts execution
5. System performs:

   * Compare → Highlight
   * Swap → Animated movement
6. Progress updates in real-time
7. Final sorted output displayed
8. Completion animation triggered
